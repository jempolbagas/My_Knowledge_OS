## The idea (one clear statement)
Quartz is an open-source, TypeScript-based static site generator that compiles Obsidian vaults and Markdown notes into fast, customizable digital gardens hosted on static web platforms.

## Why it matters / how it connects
It provides a completely free, self-hosted alternative to Obsidian Publish, natively rendering Obsidian-flavored Markdown features—including Wikilinks, latex math, callouts, and interactive graph views. Configured via `quartz.config.ts` and modular transformers/emitters, Quartz builds clean static HTML assets that can be automatically published to GitHub Pages, Cloudflare Pages, or Vercel via CI/CD workflows.
