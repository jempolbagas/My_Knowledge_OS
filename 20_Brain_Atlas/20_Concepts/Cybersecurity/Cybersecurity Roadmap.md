## The idea (one clear statement)
A Cybersecurity Roadmap is a dependency-based learning path that establishes IT, networking, and OS fundamentals before advancing through core security paradigms (CIA triad, cryptography), hands-on lab/CTF practice, and specialized tracks (Red Team, Blue Team, Cloud/GRC).

## Why it matters / how it connects
*   **Foundations First:** Effective security testing and defense require understanding operating system internals and network packet flow before attempting to use exploitation tools or SIEM systems.
*   **Specialization Tracks:** Once baseline security concepts are mastered in sandboxed environments (TryHackMe, Hack The Box), practice branches into offensive (Red Team), defensive (Blue Team), or administrative/compliance (Cloud & GRC) domains.
