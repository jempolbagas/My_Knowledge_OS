## 📌 Course Objectives & Scope
- **Karakteristik Data Biomedis:** Pemahaman format dan sifat data numeric, sinyal digital, citra medis, dan data genetik.
- **Pengolahan Citra Medis:** Pemrosesan dan penggunaan Machine Learning untuk komputasi citra X-Ray, MRI, Citra Darah, dan Citra Retina.
- **Pengolahan Sinyal Medis:** Analisis dan pemodelan Machine Learning untuk sinyal Suara, ECG (Electrocardiogram), dan EEG (Electroencephalogram).
- **Komputasi Genomik:** Pengenalan DNA, pemrosesan Micro Array, Protein, dan algoritma Machine Learning untuk komputasi gen.
- **Pemodelan Statistik & Machine Learning:** Penerapan metode statistik dan Machine Learning untuk menyelesaikan permasalahan riil di bidang biomedis.
