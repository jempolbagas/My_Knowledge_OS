## 📌 Course Objectives & Scope
- Data Preprocessing: Data cleaning, integration, transformation, reduction (PCA, feature selection).
- Association Analysis: Apriori algorithm, FP-Growth, support/confidence/lift metrics.
- Classification: Decision Trees (C4.5), Naive Bayes, K-Nearest Neighbors (KNN), Support Vector Machines (SVM).
- Clustering: K-Means, DBSCAN, Hierarchical Clustering, and model evaluation metrics (Silhouette, Confusion Matrix).
