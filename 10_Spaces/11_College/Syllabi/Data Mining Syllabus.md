## II. CAPAIAN PEMBELAJARAN & DESKRIPSI MATA KULIAH

### Capaian Pembelajaran Lulusan (CPL/LO)
* **CPLO4**: Mampu menguasai konsep-konsep terapan bidang Informatika, yang meliputi metode-metode penyediaan dan manajemen infrastruktur cloud yang efektif dan efisien, ekstraksi dan analisis data, komputasi kecerdasan buatan, deployment perangkat lunak, dan optimasi.

### Capaian Pembelajaran Mata Kuliah (CPMK)
* **CPMK251**: Mahasiswa mampu menerapkan metode-metode preprocessing dalam pengolahan data.
* **CPMK252**: Mahasiswa mampu menerapkan teknik-teknik data mining untuk menyelesaikan masalah.

### Deskripsi Mata Kuliah
Mata Kuliah Data Mining memperkenalkan mahasiswa kepada pentingnya pemahaman terhadap karakteristik Big Data dan menyelesaikan masalah yang dihadapi menggunakan pendekatan Data Mining. Lima metode yang diajarkan dalam Data Mining adalah Estimasi, Prediksi, Klasifikasi, Klastering dan Asosiasi, lengkap dengan algoritma dan metrik evaluasinya.

### Bahan Kajian (Subject Matters)
1. **Pengantar Data Mining**: Apa dan Mengapa Data Mining, Peran Utama dan Metode Data Mining, Sejarah dan Penerapan Data Mining.
2. **Proses**: Proses dan Tools Data Mining, Penerapan Proses Data Mining, Evaluasi Model Data Mining, Proses Data Mining Berbasis CRISP-DM.
3. **Persiapan Data**: Data Cleaning, Data Reduction, Data Transformation, Data Integration.
4. **Algoritma**: Algoritma Estimasi, Algoritma Prediksi, Algoritma Klasifikasi, Algoritma Klastering, Algoritma Asosiasi.
5. **Text Mining**: Konsep Text Mining, Klasifikasi Teks, Klastering Teks, Hukum Data Mining.
