# 📊 Cheatsheet: Comparative Matrix & UTBK/TOEFL Decision Tree

> **Your Emergency Formula Kit!** 🧰
> Catatan ini adalah ringkasan komprehensif yang membandingkan seluruh **Perfect Tenses** secara bersisian. Simpan dan gunakan matriks ini saat latihan ujian UTBK / TOEFL untuk identifikasi tenses secara instan!

## 1. Master Formula Comparative Table 📐

| Tense Name | Verbal Form (+) | Nominal Form (+) | Negative Form (-) | Interrogative Form (?) |
| :--- | :--- | :--- | :--- | :--- |
| **Present Perfect** | `S + have/has + V3` | `S + have/has + been + Comp` | `S + have/has + not + V3` | `Have/Has + S + V3?` |
| **Past Perfect** | `S + had + V3` | `S + had + been + Comp` | `S + had + not + V3` | `Had + S + V3?` |
| **Future Perfect** | `S + will have + V3` | `S + will have + been + Comp` | `S + will not have + V3` | `Will + S + have + V3?` |
| **Present Perfect Cont.**| `S + have/has + been + Ving`| `N/A (Stative restriction)`| `S + have/has + not + been + Ving`| `Have/Has + S + been + Ving?`|
| **Past Perfect Cont.** | `S + had + been + Ving` | `N/A (Stative restriction)`| `S + had + not + been + Ving` | `Had + S + been + Ving?` |

## 3. Exam Decision Tree: Menentukan Tenses di Soal UTBK/TOEFL 🌳

Saat mengerjakan soal pilihan ganda atau *written expression*:

```
                           [Apakah ada penanda waktu "BY + Future" atau "BY THE TIME + V1"?]
                                         /                                  \
                                       YES                                  NO
                                       /                                      \
                     [Gunakan FUTURE PERFECT]                   [Apakah ada DUA kejadian di masa lalu?]
                       (will have + V3)                               /                    \
                                                                    YES                    NO
                                                                    /                        \
                                              [Pilih mana yang TERJADI LEBIH DULU]      [Apakah berhubungan dengan SEKARANG?]
                                              - Event 1: PAST PERFECT (had + V3)         /                    \
                                              - Event 2: SIMPLE PAST (V2)              YES                    NO
                                                                                       /                        \
                                                                        [PRESENT PERFECT]           [SIMPLE PAST]
                                                                         (have/has + V3)                (V2)
```

## 4. Top 5 Rules for Error Identification (Soal Error Spotting) 🚨

1. **Rule 1 (Have vs Has):** Pastikan `has` hanya untuk subjek tunggal (*he/she/it/singular noun*), dan `have` untuk subjek jamak & *I/you/we/they*.
2. **Rule 2 (No Has After Will):** Setelah modal `will` HARUS selalu `have` (TIDAK BOLEH `will has`).
3. **Rule 3 (Verb 3 Mandate):** Semua bentuk Simple Perfect WAJIB diikuti kata kerja bentuk ketiga (`V3`), BUKAN `V2` atau `V1`.
4. **Rule 4 (No Stative Continuous):** Stative verbs (*know, love, own, belong, see*) TIDAK BOLEH berakhiran `-ing` dalam tenses sempurna; gunakan `have/has/had + V3`.
5. **Rule 5 (Past Sequence Harmony):** Jika induk kalimat berbentuk *Past*, anak kalimat tidak boleh tiba-tiba menggunakan *Present Perfect* (`have/has + V3`); ubah menjadi *Past Perfect* (`had + V3`).
