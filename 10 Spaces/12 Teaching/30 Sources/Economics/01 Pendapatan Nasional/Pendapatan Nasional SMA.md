# MASTER DASHBOARD: PENDAPATAN NASIONAL (NATIONAL INCOME)

> **Ringkasan Utama (Overview):**  
> Pendapatan nasional adalah tolok ukur utama untuk menilai kinerja perekonomian, tingkat kemakmuran masyarakat, serta laju pertumbuhan ekonomi suatu negara dalam kurun waktu satu tahun. Berkas master ini berfungsi sebagai **peta navigasi utama** yang menghubungkan seluruh modul pembelajaran tematik dan paket latihan LKPD.

## 🧮 Cheatsheet Formula Gabungan Lengkap

| Indikator / Konsep | Formula & Kriteria Utama |
| :--- | :--- |
| **GNP / PNB** | $\text{GDP} + \text{Pendapatan WNI di LN} - \text{Pendapatan WNA di DN}$ |
| **NNP / PNN** | $\text{GNP} - \text{Penyusutan (Depresiasi)}$ |
| **NNI** | $\text{NNP} - \text{Pajak Tidak Langsung} + \text{Subsidi}$ |
| **PI** | $(\text{NNI} + \text{Transfer Payment}) - (\text{Laba Ditahan} + \text{Pajak Perseroan} + \text{Iuran Pensiun})$ |
| **DI** | $\text{PI} - \text{Pajak Langsung (PPh)}$ |
| **Pendekatan Pendapatan** | $Y = w + r + i + p$ |
| **Pendekatan Produksi** | $Y = \sum \text{Nilai Tambah} = \sum (\text{Nilai Output} - \text{Nilai Input Antara})$ |
| **Pendekatan Pengeluaran** | $Y = C + I + G + (X - M)$ |
| **PDB Riil** | $\text{PDB Riil} = \left( \frac{\text{PDB Nominal}}{\text{PDB Deflator}} \right) \times 100$ |
| **Deflator PDB** | $\text{PDB Deflator} = \left( \frac{\text{PDB Nominal}}{\text{PDB Riil}} \right) \times 100$ |
| **Pendapatan Per Kapita** | $\text{Pendapatan Per Kapita} = \frac{\text{GDP atau GNP}}{\text{Jumlah Penduduk}}$ |
| **Klasifikasi Bank Dunia** | Low ($\le \$1.145$), Lower-Middle ($\$1.146-\$4.515$), Upper-Middle ($\$4.516-\$14.005$), High ($>\$14.005$) |
| **Kriteria Bank Dunia (40% Penduduk Terendah)** | $<12\%$ (Ketimpangan Tinggi), $12\%-17\%$ (Ketimpangan Sedang), $>17\%$ (Ketimpangan Rendah) |
