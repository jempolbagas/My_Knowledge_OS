# Paket Soal Evaluasi: Deret Aritmatika & Geometri 🎯

> **Catatan Pembatasan Materi:**
> Paket soal ini **berfokus murni pada DERET HINGGA ($S_n$ Aritmatika dan $S_n$ Geometri)**. Tidak mencakup materi deret geometri tak hingga ($S_\infty$).

> **Petunjuk Kerja:**
> 1. Pahami setiap soal dengan cermat sebelum menjawab.
> 2. Untuk Bagian I (Pilihan Ganda), pilih satu jawaban yang paling tepat.
> 3. Untuk Bagian II (Uraian), tuliskan langkah-langkah penyelesaian secara runtut dan jelas.

## Bagian II: Uraian / Esai (5 Soal)

## Kunci Jawaban & Pembahasan Lengkap

### Bagian I: Pilihan Ganda

1. **Jawaban: B (246)**
   * *Formula:* $S_n = \frac{n}{2}[2a + (n - 1)b]$
   * *Penyelesaian:* $S_{12} = \frac{12}{2}[2(4) + (12 - 1)3] = 6[8 + 33] = 6 \times 41 = 246$.

2. **Jawaban: C (230)**
   * *Formula:* $S_n = \frac{n}{2}(a + U_n)$
   * *Penyelesaian:* $S_{10} = \frac{10}{2}(5 + 41) = 5 \times 46 = 230$.

3. **Jawaban: A (1.010)**
   * *Cari $n$:* $98 = 3 + (n-1)5 \implies 5n = 100 \implies n = 20$.
   * *Penyelesaian:* $S_{20} = \frac{20}{2}(3 + 98) = 10 \times 101 = 1.010$.

4. **Jawaban: C (465)**
   * *Beda ($b$):* $5b = 31 - 11 = 20 \implies b = 4$.
   * *Suku pertama ($a$):* $a = 11 - 2(4) = 3$.
   * *Penyelesaian:* $S_{15} = \frac{15}{2}[2(3) + 14(4)] = 15 \times 31 = 465$.

5. **Jawaban: B (300)**
   * *Deret:* $12 + 16 + 20 + \dots + 48 \implies a=12, b=4, n=10$.
   * *Penyelesaian:* $S_{10} = \frac{10}{2}(12 + 48) = 5 \times 60 = 300$.

6. **Jawaban: B (5.050)**
   * *Penyelesaian:* $S_{100} = \frac{100}{2}(1 + 100) = 50 \times 101 = 5.050$.

7. **Jawaban: C (1.360 stel)**
   * *Penyelesaian:* $S_8 = \frac{8}{2}[2(100) + 7(20)] = 4(200 + 140) = 4 \times 340 = 1.360$.

8. **Jawaban: B (378 kursi)**
   * *Penyelesaian:* $S_{12} = \frac{12}{2}[2(15) + 11(3)] = 6(30 + 33) = 6 \times 63 = 378$.

9. **Jawaban: B (728)**
   * *Formula:* $S_n = \frac{a(r^n - 1)}{r - 1}$
   * *Penyelesaian:* $S_6 = \frac{2(3^6 - 1)}{3 - 1} = 3^6 - 1 = 729 - 1 = 728$.

10. **Jawaban: B (255)**
    * *Cari $n$:* $128 = 2^{n-1} \implies n = 8$.
    * *Penyelesaian:* $S_8 = \frac{1(2^8 - 1)}{2 - 1} = 256 - 1 = 255$.

11. **Jawaban: B (121)**
    * *Penyelesaian:* $S_5 = \frac{81(1 - (1/3)^5)}{1 - 1/3} = \frac{81 \times 242/243}{2/3} = \frac{242/3}{2/3} = 121$.

12. **Jawaban: B (189)**
    * *Rasio ($r$):* $r^2 = 24/6 = 4 \implies r = 2$, $a = 3$.
    * *Penyelesaian:* $S_6 = \frac{3(2^6 - 1)}{2 - 1} = 3 \times 63 = 189$.

13. **Jawaban: C (31)**
    * *Diketahui:* Deret Geometri $a = 16$, $r = \frac{1}{2}$, $n = 5$.
    * *Formula:* $S_n = \frac{a(1 - r^n)}{1 - r}$
    * *Penyelesaian:* $S_5 = \frac{16\left(1 - \left(\frac{1}{2}\right)^5\right)}{1 - \frac{1}{2}} = \frac{16\left(1 - \frac{1}{32}\right)}{\frac{1}{2}} = 32 \times \frac{31}{32} = 31$.

14. **Jawaban: C (200)**
    * *Diketahui:* Deret Geometri $a = 5$, $r = 3$, $n = 4$.
    * *Penyelesaian:* $S_4 = \frac{5(3^4 - 1)}{3 - 1} = \frac{5(81 - 1)}{2} = \frac{5(80)}{2} = 200$.

15. **Jawaban: B (93 cm)**
    * *Diketahui:* $a = 3$, $r = 2$, $n = 5$.
    * *Penyelesaian:* $S_5 = \frac{3(2^5 - 1)}{2 - 1} = 3(32 - 1) = 3 \times 31 = 93\text{ cm}$.

### Bagian II: Uraian / Esai

16. **Penyelesaian:**
    * Kelipatan 3 antara 50 dan 150: $51, 54, 57, \dots, 147$.
    * $n = \frac{147 - 51}{3} + 1 = 33$.
    * $S_{33} = \frac{33}{2}(51 + 147) = \frac{33}{2}(198) = 33 \times 99 = 3.267$.

17. **Penyelesaian:**
    * a. $U_{12} = 50.000 + 11(10.000) = \text{Rp } 160.000,00$.
    * b. $S_{24} = \frac{24}{2}[2(50.000) + 23(10.000)] = 12(330.000) = \text{Rp } 3.960.000,00$.

18. **Penyelesaian:**
    * $S_7 = \frac{4(2^7 - 1)}{2 - 1} = 4(128 - 1) = 4 \times 127 = 508$.

19. **Penyelesaian:**
    * a. **Banyaknya sel tiap periode waktu:**
      * Menit ke-0 ($U_1$): 4 sel
      * Menit ke-10 ($U_2$): 8 sel
      * Menit ke-20 ($U_3$): 16 sel
      * Menit ke-30 ($U_4$): 32 sel
      * Menit ke-40 ($U_5$): 64 sel
    * b. **Akumulasi total sel ($S_5$):**
      $$S_5 = \frac{a(r^5 - 1)}{r - 1} = \frac{4(2^5 - 1)}{2 - 1} = 4(32 - 1) = 4 \times 31 = 124\text{ sel}$$
    * *Kesimpulan:* Akumulasi total sel dari menit ke-0 hingga menit ke-40 adalah **124 sel**.

20. **Penyelesaian:**
    * a. $S_5 = 2(5)^2 + 3(5) = 50 + 15 = 65$.
    * b. $a = S_1 = 2(1)^2 + 3(1) = 5$.
      $S_2 = 2(2)^2 + 3(2) = 14 \implies U_2 = 14 - 5 = 9$.
      Beda $b = U_2 - a = 9 - 5 = 4$.
