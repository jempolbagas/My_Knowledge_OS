Paket soal ini dirancang khusus untuk menguji penalaran matematis tingkat tinggi (*Higher Order Thinking Skills*), analisis grafik gelombang tergeser, manipulasi aljabar analitik rumus jumlah/selisih, pembuktian identitas kompleks, dan penyelesaian masalah geometri pemodelan nyata.

## ✍️ BAGIAN B: Soal Esai Penalaran Lanjut (5 Butir)

**1.** Buktikan secara analitis identitas trigonometri berikut:
   $$\frac{\cos(3x) - \cos(5x)}{\sin(5x) + \sin(3x)} = \tan x$$

**2.** Diketahui persamaan trigonometri kuadratik:
   $$2\cos^2 x - 5\sin x + 1 = 0$$
   Tentukan seluruh Himpunan Penyelesaian (HP) untuk interval $0^\circ \le x \le 360^\circ$.

**3.** Suatu kincir ria (*Ferris wheel*) raksasa berdiameter $40\text{ meter}$ berputar berlawanan arah jarum jam dengan kecepatan konstan, menyelesaikan $1$ putaran penuh dalam waktu $4\text{ menit}$. Titik terendah kincir berada $2\text{ meter}$ di atas permukaan tanah. Penumpang menaiki wahana pada saat $t = 0$ di titik terendah.
   a. Susunlah rumus fungsi ketinggian penumpang $H(t)$ (dalam meter) terhadap waktu $t$ (dalam menit).
   b. Hitung ketinggian penumpang tepat pada menit ke-$3$.
   c. Pada interval putaran pertama ($0 \le t \le 4$), tentukan seluruh rentang waktu ketika penumpang berada pada ketinggian **minimal $32\text{ meter}$** di atas tanah.

**4.** Pada segitiga sebarang $\triangle ABC$, buktikan bahwa berlaku hubungan:
   $$\frac{a + b}{c} = \frac{\cos\left(\frac{A - B}{2}\right)}{\sin\left(\frac{C}{2}\right)}$$
   *(Petunjuk: Gunakan Aturan Sinus dan rumus penjumlahan ke perkalian).*

**5.** Tentukan nilai eksak dari penjumlahan deret trigonometri berhingga berikut tanpa kalkulator:
   $$S = \sin^2(1^\circ) + \sin^2(2^\circ) + \sin^2(3^\circ) + \dots + \sin^2(89^\circ) + \sin^2(90^\circ)$$

## 🔑 KUNCI JAWABAN & PEMBAHASAN ANALITIS LENGKAP

### Pembahasan Bagian A (Pilihan Ganda)

1. **Jawaban: A ($-\frac{8}{9}$)**  
   * Kuadratkan kedua ruas persamaan $\sin x + \cos x = \frac{1}{3}$:
     $$(\sin x + \cos x)^2 = \left(\frac{1}{3}\right)^2$$
     $$\sin^2 x + 2\sin x \cos x + \cos^2 x = \frac{1}{9}$$
   * Mengingat $\sin^2 x + \cos^2 x = 1$ dan $2\sin x \cos x = \sin(2x)$:
     $$1 + \sin(2x) = \frac{1}{9} \implies \sin(2x) = \frac{1}{9} - 1 = -\frac{8}{9}$$.

2. **Jawaban: C ($\frac{1}{8}$)**  
   * Kalikan dan bagi bentuk ekspresi dengan $2\sin 20^\circ$:
     $$E = \frac{2\sin 20^\circ \cos 20^\circ \cos 40^\circ \cos 80^\circ}{2\sin 20^\circ} = \frac{\sin 40^\circ \cos 40^\circ \cos 80^\circ}{2\sin 20^\circ}$$
   * Kalikan pembilang dan penyebut dengan $2$:
     $$E = \frac{2\sin 40^\circ \cos 40^\circ \cos 80^\circ}{4\sin 20^\circ} = \frac{\sin 80^\circ \cos 80^\circ}{4\sin 20^\circ} = \frac{2\sin 80^\circ \cos 80^\circ}{8\sin 20^\circ} = \frac{\sin 160^\circ}{8\sin 20^\circ}$$
   * Karena $\sin 160^\circ = \sin(180^\circ - 20^\circ) = \sin 20^\circ$:
     $$E = \frac{\sin 20^\circ}{8\sin 20^\circ} = \frac{1}{8}$$.

3. **Jawaban: A ($4 + \pi$)**  
   * Fungsi $f(x) = -3\cos(2x - \pi/3) + 2$:
     * Amplitudo $|A| = |-3| = 3$.
     * Pergeseran vertikal $c = 2$.
     * $M = y_{\max} = 3 + 2 = 5$.
     * $m = y_{\min} = -3 + 2 = -1$.
     * Periode $T = \frac{2\pi}{k} = \frac{2\pi}{2} = \pi$.
   * $M + m + T = 5 + (-1) + \pi = 4 + \pi$.

4. **Jawaban: C ($4$)**  
   * Gunakan identitas $\cos(2x) = 1 - 2\sin^2 x$:
     $$(1 - 2\sin^2 x) + \sin x = 1 \implies -2\sin^2 x + \sin x = 0 \implies \sin x (1 - 2\sin x) = 0$$
   * Kasus 1 ($\sin x = 0$): Pada interval $[0, 2\pi]$, solusinya adalah $x = 0, \pi, 2\pi$ ($3$ solusi).
   * Kasus 2 ($\sin x = \frac{1}{2}$): Solusinya adalah $x = \frac{\pi}{6}, \frac{5\pi}{6}$ ($2$ solusi).
   * Namun perhatikan bahwa $x=0, \pi/6, 5\pi/6, \pi, 2\pi$ ada total **5 solusi** jika $2\pi$ inklusif. *(Koreksi: Pilihan D bernilai 5).*

5. **Jawaban: A ($\frac{1 - p^2}{2p}$)**  
   * $\tan 160^\circ = \tan(180^\circ - 20^\circ) = -\tan 20^\circ = -p$.
   * $\tan 110^\circ = \tan(90^\circ + 20^\circ) = -\cot 20^\circ = -\frac{1}{p}$.
   * Substitusi:
     $$\text{Pembilang} = (-p) - \left(-\frac{1}{p}\right) = \frac{1}{p} - p = \frac{1 - p^2}{p}$$
     $$\text{Penyebut} = 1 + (-p)\left(-\frac{1}{p}\right) = 1 + 1 = 2$$
     $$\text{Hasil} = \frac{\frac{1-p^2}{p}}{2} = \frac{1-p^2}{2p}$$.

6. **Jawaban: A ($14$)**  
   * Luas segitiga $L = \frac{1}{2} a b \sin C \implies 15\sqrt{3} = \frac{1}{2}(6)(10)\sin C \implies 15\sqrt{3} = 30\sin C \implies \sin C = \frac{\sqrt{3}}{2}$.
   * Karena $\angle C$ sudut tumpul: $C = 180^\circ - 60^\circ = 120^\circ$.
   * Gunakan Aturan Cosinus:
     $$c^2 = a^2 + b^2 - 2ab\cos C = 6^2 + 10^2 - 2(6)(10)\cos 120^\circ$$
     $$c^2 = 36 + 100 - 120\left(-\frac{1}{2}\right) = 136 + 60 = 196 \implies c = \sqrt{196} = 14$$.

7. **Jawaban: C ($\tan(4x)$)**  
   * Rumus Sum-to-Product:
     * $\sin(5x) + \sin(3x) = 2\sin\left(\frac{5x+3x}{2}\right)\cos\left(\frac{5x-3x}{2}\right) = 2\sin(4x)\cos(x)$
     * $\cos(5x) + \cos(3x) = 2\cos\left(\frac{5x+3x}{2}\right)\cos\left(\frac{5x-3x}{2}\right) = 2\cos(4x)\cos(x)$
   * Pecahan: $\frac{2\sin(4x)\cos(x)}{2\cos(4x)\cos(x)} = \frac{\sin(4x)}{\cos(4x)} = \tan(4x)$.

8. **Jawaban: C ($2$)**  
   * Jabarkan: $(1 + \tan \alpha)(1 + \tan \beta) = 1 + \tan \alpha + \tan \beta + \tan \alpha \tan \beta$.
   * Dari rumus tangen: $\tan(\alpha + \beta) = \frac{\tan \alpha + \tan \beta}{1 - \tan \alpha \tan \beta} = \tan\left(\frac{\pi}{4}\right) = 1$.
   * Maka: $\tan \alpha + \tan \beta = 1 - \tan \alpha \tan \beta \implies \tan \alpha + \tan \beta + \tan \alpha \tan \beta = 1$.
   * Sehingga: $1 + 1 = 2$.

9. **Jawaban: A ($100(1 - \frac{1}{3}\sqrt{3})\text{ meter}$)**  
   * Jarak $d = 100\text{ m}$.
   * Tinggi tebing $t_1 = d \cdot \tan 30^\circ = 100 \cdot \frac{1}{3}\sqrt{3} = \frac{100\sqrt{3}}{3}\text{ m}$.
   * Tinggi total tebing + mercusuar $t_2 = d \cdot \tan 45^\circ = 100 \cdot 1 = 100\text{ m}$.
   * Tinggi mercusuar $h = t_2 - t_1 = 100 - \frac{100\sqrt{3}}{3} = 100\left(1 - \frac{1}{3}\sqrt{3}\right)\text{ m}$.

10. **Jawaban: D ($\frac{7\pi}{6} < x < \frac{3\pi}{2}$ atau $\frac{3\pi}{2} < x < \frac{11\pi}{6}$)**  
    * Faktorkan: $(2\sin x + 1)(\sin x - 1) > 0$.
    * Pembuat nol: $\sin x = -\frac{1}{2}$ atau $\sin x = 1$.
    * Karena $\sin x \le 1$, faktor $(\sin x - 1) \le 0$. Agar perkalian bernilai positif ($>0$), haruslah $(\sin x - 1) < 0$ dan $(2\sin x + 1) < 0 \implies \sin x < -\frac{1}{2}$ (dengan $\sin x \ne 1$).
    * Nilai $\sin x < -\frac{1}{2}$ terjadi pada rentang $\frac{7\pi}{6} < x < \frac{11\pi}{6}$.

### Pembahasan Bagian B (Uraian HOTS)

1. **Pembuktian Identitas Analitis:**
   * Pembilang: $\cos(3x) - \cos(5x) = -2\sin\left(\frac{3x+5x}{2}\right)\sin\left(\frac{3x-5x}{2}\right) = -2\sin(4x)\sin(-x) = 2\sin(4x)\sin(x)$ (karena $\sin(-x) = -\sin x$).
   * Penyebut: $\sin(5x) + \sin(3x) = 2\sin(4x)\cos(x)$.
   * Hasil bagi: $\text{LHS} = \frac{2\sin(4x)\sin x}{2\sin(4x)\cos x} = \frac{\sin x}{\cos x} = \tan x = \text{RHS} \quad \mathbf{[TERBUKTI]}$.

2. **Persamaan Kuadratik Trigonometri:**
   * Ubah $\cos^2 x = 1 - \sin^2 x$:
     $$2(1 - \sin^2 x) - 5\sin x + 1 = 0 \implies -2\sin^2 x - 5\sin x + 3 = 0$$
     $$2\sin^2 x + 5\sin x - 3 = 0 \implies (2\sin x - 1)(\sin x + 3) = 0$$
   * Akar 1: $\sin x + 3 = 0 \implies \sin x = -3$ *(Tidak Memenuhi karena di luar $[-1,1]$)*.
   * Akar 2: $2\sin x - 1 = 0 \implies \sin x = \frac{1}{2}$.
   * Sudut dalam interval $[0^\circ, 360^\circ]$:
     * $x_1 = \mathbf{30^\circ}$
     * $x_2 = 180^\circ - 30^\circ = \mathbf{150^\circ}$
   * $\mathbf{HP = \{30^\circ, 150^\circ\}}$.

3. **Pemodelan Ferris Wheel:**
   * a. Parameter: Jari-jari $R = \frac{40}{2} = 20\text{ m}$. Garis tengah $c = 2 + 20 = 22\text{ m}$. Amplitudo $A = 20$. Periode $T = 4\text{ menit} \implies k = \frac{2\pi}{4} = \frac{\pi}{2}$.
     Karena mulai di titik terendah saat $t = 0$, fungsi berbentuk kosinus terbalik:
     $$\mathbf{H(t) = -20\cos\left(\frac{\pi}{2}t\right) + 22}$$
   * b. Pada $t = 3$:
     $$H(3) = -20\cos\left(\frac{3\pi}{2}\right) + 22 = -20(0) + 22 = \mathbf{22\text{ meter}}$$.
   * c. Syarat ketinggian $H(t) \ge 32$:
     $$-20\cos\left(\frac{\pi}{2}t\right) + 22 \ge 32 \implies -20\cos\left(\frac{\pi}{2}t\right) \ge 10 \implies \cos\left(\frac{\pi}{2}t\right) \le -\frac{1}{2}$$
     * Nilai sudut $\cos \theta \le -\frac{1}{2}$ terjadi saat $\frac{2\pi}{3} \le \theta \le \frac{4\pi}{3}$.
     * Maka $\frac{2\pi}{3} \le \frac{\pi}{2}t \le \frac{4\pi}{3} \implies \mathbf{\frac{4}{3}\text{ menit} \le t \le \frac{8}{3}\text{ menit}}$ (antara menit ke-$1$ detik $20$ hingga menit ke-$2$ detik $40$).

4. **Pembuktian Relasi Segitiga Sebarang:**
   * Berdasarkan Aturan Sinus: $a = 2R\sin A$, $b = 2R\sin B$, $c = 2R\sin C$.
   * Sisi kiri: $\frac{a+b}{c} = \frac{2R\sin A + 2R\sin B}{2R\sin C} = \frac{\sin A + \sin B}{\sin C}$.
   * Terapkan rumus penjumlahan sinus pada pembilang dan sudut rangkap pada penyebut:
     $$\sin A + \sin B = 2\sin\left(\frac{A+B}{2}\right)\cos\left(\frac{A-B}{2}\right)$$
     $$\sin C = 2\sin\left(\frac{C}{2}\right)\cos\left(\frac{C}{2}\right)$$
   * Karena dalam segitiga $A+B+C = 180^\circ \implies \frac{A+B}{2} = 90^\circ - \frac{C}{2}$, maka $\sin\left(\frac{A+B}{2}\right) = \cos\left(\frac{C}{2}\right)$.
   * Substitusi:
     $$\frac{a+b}{c} = \frac{2\cos\left(\frac{C}{2}\right)\cos\left(\frac{A-B}{2}\right)}{2\sin\left(\frac{C}{2}\right)\cos\left(\frac{C}{2}\right)} = \mathbf{\frac{\cos\left(\frac{A-B}{2}\right)}{\sin\left(\frac{C}{2}\right)}} \quad \mathbf{[TERBUKTI]}$$

5. **Penjumlahan Deret Trigonometri:**
   * Pasangkan suku-suku komplementer:
     $\sin^2(89^\circ) = \sin^2(90^\circ - 1^\circ) = \cos^2(1^\circ)$.
     Sehingga $\sin^2(1^\circ) + \sin^2(89^\circ) = \sin^2(1^\circ) + \cos^2(1^\circ) = 1$.
   * Ada $44$ pasang yang berjumlah $1$: $(1^\circ, 89^\circ), (2^\circ, 88^\circ), \dots, (44^\circ, 46^\circ) \implies 44 \times 1 = 44$.
   * Sisa suku yang tidak berpasangan:
     * $\sin^2(45^\circ) = \left(\frac{1}{2}\sqrt{2}\right)^2 = \frac{1}{2}$
     * $\sin^2(90^\circ) = 1^2 = 1$
   * Total $S = 44 + \frac{1}{2} + 1 = \mathbf{45\frac{1}{2}} = \mathbf{45,5}$.
