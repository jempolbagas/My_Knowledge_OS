## 📝 BAGIAN A: PILIHAN GANDA (10 SOAL HOTS)

### 1. Kesamaan Polinomial dengan 3 Parameter
Diketahui kesamaan aljabar berikut:
$$x^2 + 4x + 1 \equiv A(x + 1)^2 + B(x + 1) + C$$
Nilai dari $A + B + C$ adalah...  
A. $-1$  
B. $0$  
C. $1$  
D. $3$  
E. $5$

## 🔑 KUNCI JAWABAN & PEMBAHASAN LENGKAP

### Pembahasan Bagian A (Pilihan Ganda)

#### 1. Kunci Jawaban: C ($1$)
* **Pembahasan:**  
  Metode substitusi pembuat nol:  
  Untuk $x = -1$:
  $$(-1)^2 + 4(-1) + 1 = A(-1 + 1)^2 + B(-1 + 1) + C \implies 1 - 4 + 1 = C \implies C = -2$$
  Jabarkan ruas kanan kesamaan aljabar:
  $$A(x^2 + 2x + 1) + B(x + 1) + C = Ax^2 + (2A + B)x + (A + B + C)$$
  Samakan koefisien dengan ruas kiri $x^2 + 4x + 1$:
  * Koefisien $x^2$: $A = 1$.
  * Koefisien $x$: $2A + B = 4 \implies 2(1) + B = 4 \implies B = 2$.
  * Nilai $A + B + C = 1 + 2 + (-2) = 1$.

#### 2. Kunci Jawaban: D ($19$)
* **Pembahasan:**  
  Pembagi $x^2 - 1 = (x - 1)(x + 1)$.  
  Karena $P(x)$ habis dibagi $(x^2 - 1)$, maka $P(1) = 0$ dan $P(-1) = 0$.
  * $P(1) = 1^4 + a(1)^3 + b(1)^2 - 5(1) + 6 = 0 \implies 1 + a + b - 5 + 6 = 0 \implies a + b = -2$
  * $P(-1) = (-1)^4 + a(-1)^3 + b(-1)^2 - 5(-1) + 6 = 0 \implies 1 - a + b + 5 + 6 = 0 \implies a - b = 12$
  
  Jumlahkan kedua persamaan:
  $$2a = 10 \implies a = 5$$
  Substitusi $a = 5 \implies 5 + b = -2 \implies b = -7$.  
  Nilai $a - 2b = 5 - 2(-7) = 5 + 14 = 19$.

#### 3. Kunci Jawaban: A ($x^2 + 3$)
* **Pembahasan:**  
  Pembagi $(x - 1)(x - 2)(x + 3)$ berderajat 3, sehingga sisa pembagian berbentuk $S(x) = ax^2 + bx + c$.
  Berdasarkan Teorema Sisa:
  * $f(1) = a + b + c = 4 \quad \text{--- (Pers 1)}$
  * $f(2) = 4a + 2b + c = 7 \quad \text{--- (Pers 2)}$
  * $f(-3) = 9a - 3b + c = 12 \quad \text{--- (Pers 3)}$
  
  Kurangkan (Pers 2) - (Pers 1): $3a + b = 3 \implies b = 3 - 3a$.  
  Kurangkan (Pers 3) - (Pers 1): $8a - 4b = 8 \implies 2a - b = 2$.  
  Substitusi $b = 3 - 3a$:
  $$2a - (3 - 3a) = 2 \implies 5a = 5 \implies a = 1$$
  Substitusi $a = 1 \implies b = 0$.  
  Substitusi $a = 1, b = 0 \implies 1 + 0 + c = 4 \implies c = 3$.  
  Maka sisa pembagian adalah $S(x) = x^2 + 3$.

#### 4. Kunci Jawaban: C ($4$)
* **Pembahasan:**  
  Karena $P(x) = x^3 + ax + b$ habis dibagi oleh $(x - 2)^2 = x^2 - 4x + 4$, maka dapat dituliskan:
  $$x^3 + ax + b \equiv (x^2 - 4x + 4)(x - c)$$
  $$x^3 + ax + b \equiv x^3 - (c + 4)x^2 + (4c + 4)x - 4c$$
  Samakan koefisien:
  * Koefisien $x^2$: $c + 4 = 0 \implies c = -4$.
  * Koefisien $x$: $a = 4c + 4 = 4(-4) + 4 = -12$.
  * Suku Tetap: $b = -4c = -4(-4) = 16$.
  
  Nilai dari $a + b = -12 + 16 = 4$.

#### 5. Kunci Jawaban: D ($18$)
* **Pembahasan:**  
  Polinomial dapat dituliskan sebagai pemfaktoran akar-akarnya:
  $$P(x) = x^3 - 5x^2 + 8x - 4 = (x - x_1)(x - x_2)(x - x_3)$$
  Perhatikan bahwa:
  $$(x_1 + 1)(x_2 + 1)(x_3 + 1) = -(-1 - x_1)(-1 - x_2)(-1 - x_3) = -P(-1)$$
  Hitung nilai $P(-1)$:
  $$P(-1) = (-1)^3 - 5(-1)^2 + 8(-1) - 4 = -1 - 5 - 8 - 4 = -18$$
  Maka nilai $(x_1 + 1)(x_2 + 1)(x_3 + 1) = -(-18) = 18$.

#### 6. Kunci Jawaban: A ($-5$)
* **Pembahasan:**  
  Sisa pembagian $f(x) \cdot g(x)$ oleh $(x - 2)$ menurut Teorema Sisa adalah nilai $f(2) \cdot g(2)$.  
  Karena pembagi $(x^2 - 4) = (x - 2)(x + 2)$:
  * $f(2) = 2(2) + 1 = 5$
  * $g(2) = 2 - 3 = -1$
  
  Maka nilai sisa pembagian adalah $f(2) \cdot g(2) = 5 \cdot (-1) = -5$.

#### 7. Kunci Jawaban: C ($2$)
* **Pembahasan:**  
  Uji akar rasional dari persamaan $x^4 - 2x^3 - x^2 - 4x - 6 = 0$:
  * Untuk $x = 3 \implies 3^4 - 2(3)^3 - 3^2 - 4(3) - 6 = 81 - 54 - 9 - 12 - 6 = 0$
  * Untuk $x = -1 \implies (-1)^4 - 2(-1)^3 - (-1)^2 - 4(-1) - 6 = 1 + 2 - 1 + 4 - 6 = 0$
  
  Bagi polinomial dengan $(x - 3)(x + 1) = x^2 - 2x - 3$:
  $$\frac{x^4 - 2x^3 - x^2 - 4x - 6}{x^2 - 2x - 3} = x^2 + 2$$
  Persamaan $x^2 + 2 = 0$ tidak memiliki akar real (akarnya imajiner $\pm i\sqrt{2}$).  
  Sehingga banyaknya akar real yang memenuhi adalah **2 akar real** ($x = 3$ dan $x = -1$).

#### 8. Kunci Jawaban: A ($-18$)
* **Pembahasan:**  
  Berdasarkan Teorema Vieta untuk $x^3 - 7x + 6 = 0$:
  * $\alpha + \beta + \gamma = 0$
  * $\alpha\beta\gamma = -6$
  
  Gunakan identitas aljabar kubik:
  $$\alpha^3 + \beta^3 + \gamma^3 - 3\alpha\beta\gamma = (\alpha + \beta + \gamma)(\alpha^2 + \beta^2 + \gamma^2 - \alpha\beta - \alpha\gamma - \beta\gamma)$$
  Karena $(\alpha + \beta + \gamma) = 0$, maka:
  $$\alpha^3 + \beta^3 + \gamma^3 = 3\alpha\beta\gamma = 3(-6) = -18$$

#### 9. Kunci Jawaban: A (Derajat $H(x) = 4$ dan derajat $S(x)$ maksimum $= 2$)
* **Pembahasan:**  
  * Derajat Hasil Bagi $H(x) = \text{derajat } f(x) - \text{derajat } g(x) = 7 - 3 = 4$.
  * Derajat maksimum Sisa Pembagian $S(x) = \text{derajat } g(x) - 1 = 3 - 1 = 2$.

#### 10. Kunci Jawaban: B ($2\text{ unit}$)
* **Pembahasan:**  
  Keuntungan total $P(x) = R(x) - C(x)$:
  $$P(x) = (3x^2 + 6x + 8) - (x^3 - 4x^2 + 10x + 20)$$
  $$P(x) = -x^3 + 7x^2 - 4x - 12$$
  Kondisi titik impas terjadi saat $P(x) = 0$:
  $$-x^3 + 7x^2 - 4x - 12 = 0 \iff x^3 - 7x^2 + 4x + 12 = 0$$
  Uji akar rasional $x = 2$:
  $$2^3 - 7(2)^2 + 4(2) + 12 = 8 - 28 + 8 + 12 = 0 \quad (\text{Memenuhi!})$$
  Jadi titik impas dicapai saat jumlah produksi $x = 2\text{ unit}$.

### Pembahasan Bagian B (Soal Uraian)

#### Soal 1 (Skor Maksimal: 15)
* **Langkah 1:** Substitusi Pembuat Nol.  
  Substitusikan $x = 1$ ke kedua ruas:
  $$1^3 = A(1 - 1)^3 + B(1 - 1)^2 + C(1 - 1) + D \implies D = 1$$

* **Langkah 2:** Jabarkan Ruas Kanan Menggunakan Ekspansi Binomial.
  $$x^3 \equiv A(x^3 - 3x^2 + 3x - 1) + B(x^2 - 2x + 1) + C(x - 1) + D$$
  $$x^3 \equiv Ax^3 + (-3A + B)x^2 + (3A - 2B + C)x + (-A + B - C + D)$$

* **Langkah 3:** Penyetaraan Koefisien.
  1. Koefisien $x^3$: $A = 1$.
  2. Koefisien $x^2$: $-3A + B = 0 \implies -3(1) + B = 0 \implies B = 3$.
  3. Koefisien $x$: $3A - 2B + C = 0 \implies 3(1) - 2(3) + C = 0 \implies C = 3$.
  4. Konfirmasi Konstanta: $-A + B - C + D = -1 + 3 - 3 + 1 = 0$ (Terbukti cocok).

* **Kesimpulan:** Nilai $A = 1$, $B = 3$, $C = 3$, dan $D = 1$.

---

#### Soal 2 (Skor Maksimal: 20)
* **a. Menentukan Nilai $a$ dan $b$ (Horner Berulang):**
  Lakukan Skema Horner berturut-turut dengan pembagi $x = 1$:
  * **Horner 1:**
    ```text
    1 | 1    a      b        -8          4
      |      1     a+1     a+b+1     a+b-7
      ---------------------------------- +
        1   a+1   a+b+1   a+b-7   |  a+b-3
    ```
    Sisa 1 must be $0 \implies a + b - 3 = 0 \implies a + b = 3$.

  * **Horner 2 (pada koefisien hasil bagi Horner 1):**
    ```text
    1 | 1   a+1    a+b+1      a+b-7
      |     1      a+2        2a+b+3
      --------------------------------- +
        1   a+2   2a+b+3   |  3a+2b-4
    ```
    Sisa 2 must be $0 \implies 3a + 2b - 4 = 0$.

  Sistem Persamaan:
  $$\begin{cases} 2a + 2b = 6 \\ 3a + 2b = 4 \end{cases} \implies a = -2, \quad b = 5$$

* **b. Hasil Bagi $H(x)$:**
  Koefisien hasil bagi diambil dari baris terakhir Horner 2:
  $$H(x) = x^2 + (a + 2)x + (2a + b + 3)$$
  Substitusikan $a = -2$ dan $b = 5$:
  $$H(x) = x^2 + (-2 + 2)x + (2(-2) + 5 + 3) = x^2 + 4$$

#### Soal 3 (Skor Maksimal: 20)
* **a. Menentukan Nilai $P(1), P(2),$ dan $P(3)$:**
  * Dari pembagi $(x^2 - 3x + 2) = (x - 1)(x - 2)$ sisa $(3x - 1)$:
    * $P(1) = 3(1) - 1 = 2$
    * $P(2) = 3(2) - 1 = 5$
  * Dari pembagi $(x^2 - 5x + 6) = (x - 2)(x - 3)$ sisa $(5x - 5)$:
    * $P(2) = 5(2) - 5 = 5 \quad (\text{Konsisten!})$
    * $P(3) = 5(3) - 5 = 10$

* **b. Sisa Pembagian oleh $(x^2 - 4x + 3)$:**
  Pembagi $(x^2 - 4x + 3) = (x - 1)(x - 3)$. Misalkan sisa $S(x) = ax + b$.
  * $P(1) = a + b = 2$
  * $P(3) = 3a + b = 10$
  
  Kurangkan kedua persamaan:
  $$2a = 8 \implies a = 4 \implies b = -2$$
  Maka sisa pembagian $P(x)$ oleh $(x^2 - 4x + 3)$ adalah $S(x) = 4x - 2$.

---

#### Soal 4 (Skor Maksimal: 25)
* **a. Pembuktian Akar Aljabar:**
  Substitusikan $x = -1$ dan $x = 2$ ke $x^4 - 2x^3 - 7x^2 + 8x + 12 = 0$:
  * Untuk $x = -1$: $(-1)^4 - 2(-1)^3 - 7(-1)^2 + 8(-1) + 12 = 1 + 2 - 7 - 8 + 12 = 0 \quad (\text{Terbukti!})$
  * Untuk $x = 2$: $2^4 - 2(2)^3 - 7(2)^2 + 8(2) + 12 = 16 - 16 - 28 + 16 + 12 = 0 \quad (\text{Terbukti!})$

* **b. Pemfaktoran Linier & Himpunan Penyelesaian:**
  Bagi polinomial dengan $(x + 1)(x - 2) = x^2 - x - 2$:
  $$\frac{x^4 - 2x^3 - 7x^2 + 8x + 12}{x^2 - x - 2} = x^2 - x - 6$$
  Faktorkan $x^2 - x - 6 = (x - 3)(x + 2)$.
  * **Faktor Linier Lengkap:** $(x + 1)(x - 2)(x - 3)(x + 2) = 0$
  * **Himpunan Penyelesaian (HP):** $x \in \{-2, -1, 2, 3\}$

---

#### Soal 5 (Skor Maksimal: 25)
* **a. Menentukan Akar-Akar (Barisan Aritmatika):**
  Misalkan akar-akar aritmatika: $x_1 = a - d, x_2 = a, x_3 = a + d$.  
  Berdasarkan Teorema Vieta:
  $$x_1 + x_2 + x_3 = 3a = 12 \implies a = 4 \implies x_2 = 4$$
  Bagi $x^3 - 12x^2 + 44x - 48$ dengan $(x - 4)$ memakai Horner:
  ```text
  4 | 1  -12   44  -48
    |       4  -32   48
    -------------------- +
        1   -8   12 |   0
  ```
  Hasil bagi $x^2 - 8x + 12 = (x - 2)(x - 6) = 0 \implies x = 2$ atau $x = 6$.  
  Karena $x_1 < x_2 < x_3$, maka $x_1 = 2, x_2 = 4, x_3 = 6$.

* **b. Menghitung Nilai Ekspresi Pecahan Akar:**
  $$\frac{1}{x_1 x_2} + \frac{1}{x_2 x_3} + \frac{1}{x_1 x_3} = \frac{x_3 + x_1 + x_2}{x_1 x_2 x_3}$$
  Berdasarkan Teorema Vieta:
  * Jumlah akar $x_1 + x_2 + x_3 = 12$
  * Hasil kali ketiga akar $x_1 x_2 x_3 = 48$
  
  $$\text{Nilai Ekspresi} = \frac{12}{48} = \frac{1}{4}$$
