## 🎯 Capaian & Tujuan Pembelajaran
Setelah menyelesaikan lembar aktivitas ini, kamu diharapkan mampu:
1. Memprediksi kecenderungan atom suatu unsur mencapai kestabilan (duplet/oktet) serta menggambar lambang titik Lewis dengan tepat.
2. Membedakan mekanisme pembentukan ikatan ion (transfer elektron) dan ikatan kovalen (pemakaian bersama elektron).
3. Menganalisis kepolaran senyawa kovalen berdasarkan perbedaan keelektronegatifan dan bentuk molekulnya.
4. Menghubungkan jenis ikatan kimia (ion, kovalen, logam) dengan sifat fisis makroskopis zat (titik leleh, daya hantar listrik, kelarutan, dan kelenturan).

## 🚀 Aktivitas 4: Tantangan Penalaran HOTS & Material Maju

### Kasus: Misteri Intan vs Grafit (Dua Saudara Kandung dengan Nasib Berbeda)
Intan dan Grafit sama-sama tersusun $100\%$ dari atom Karbon ($\text{C}$) murni. Namun:
- **Intan** adalah material alami paling keras di bumi, transparan, dan merupakan isolator listrik sempurna.
- **Grafit** berwarna hitam kelabu, permukaannya sangat licin dan mudah terkelupas (sehingga dipakai untuk isi pensil), serta **mampu menghantarkan arus listrik dengan sangat baik**.

```
             STRUKTUR INTAN (3D)                         STRUKTUR GRAFIT (2D Layered)
                   C                                          C ── C ── C ── C
                 / | \                                       /    \    /    \
                C  C  C                                     C ── C ── C ── C
               / \   / \                                    ════════════════════ (Lautan e- bebas)
              C   C C   C                                   C ── C ── C ── C
           (Tetrahedral Kaku 3D)                            (Lapisan Heksagonal 2D)
```

**Tugas Kelompok:**  
Analisislah struktur ikatan kovalen pada intan dan grafit! Mengapa pada grafit terdapat elektron yang terdelokalisasi sehingga mampu menghantarkan arus listrik? Tuliskan penjelasan ilmiah kelompokmu secara komprehensif!
